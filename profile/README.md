## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Does this repository include a map hack executable?

No. It provides reference information about map reveal mechanics and the game's documented debug features.

### Can Civilization VI reveal the entire map?

Yes. The PC debug console includes a `Reveal All` command that removes the fog of war. The `Explore All` command is also documented as a map exploration option.

### Does map reveal show enemy units everywhere?

The official manual distinguishes between currently visible and previously revealed tiles. Previously explored areas can retain terrain and permanent features without displaying units that are no longer visible.

### Is there a normal gameplay method to reveal the entire map?

Yes. Completing the Launch Earth Satellite project reveals the world map as part of the science victory path. This is different from using the debug console.
